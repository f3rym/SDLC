**Преподаватель:** Куприянова Д. В.
**Год:** 2026

## О проекте

Репозиторий является форком учебного репозитория [BSUIR-SDLC/SDLC](https://github.com/BSUIR-SDLC/SDLC)
с шаблонами проектной документации (SRS, SDD, ADR). В нём выполняется цикл лабораторных работ
по дисциплине: от настройки среды и системы контроля версий до проектирования и разработки
приложения по варианту 8.

**Разрабатываемое приложение — DeadlineGuard** (с ЛР3): веб-приложение «Трекер дедлайнов для студентов».
Календарь с жёсткой привязкой сроков к датам, автоматическими уровнями эскалации и напоминаниями
(в приложении → e-mail → Telegram); если студент не реагирует на критичный дедлайн, уведомление получает
выбранное им контрольное лицо. Стек: Java 21, Spring Boot 3, Thymeleaf, PostgreSQL.
Требования — [`srs/srs-deadlineguard.md`](srs/srs-deadlineguard.md), дизайн — [`sdd/sdd-deadlineguard.md`](sdd/sdd-deadlineguard.md), решения — [`adr/`](adr), план реализации — [`plan/iteration-plan.md`](plan/iteration-plan.md).

## Структура репозитория

| Папка / файл | Содержимое |
|--------------|------------|
| `srs/`, `sdd/`, `adr/`, `docs/` | шаблоны и справочные материалы исходного репозитория |
| `srs/srs-deadlineguard.md` | спецификация требований DeadlineGuard (ЛР3) |
| `srs/models/`, `srs/images/` | модели SysML v2 и их PNG: контекст, варианты использования, автомат эскалации, макеты экранов |
| `sdd/sdd-deadlineguard.md` | описание дизайна DeadlineGuard (ЛР4) |
| `sdd/models/`, `sdd/images/` | модели SysML v2 дизайна: модули, модель данных, доставка напоминаний, развёртывание |
| `adr/0001…0005-*.md` | архитектурные решения в формате MADR (ЛР4) |
| `plan/iteration-plan.md`, `plan/correspondence.md`, `plan/chat/` | оценки, приоритеты 10–50, планы v1–v3 и переписка с Заказчиком в Telegram со скриншотами (ЛР4) |
| `project/` | проект приложения (проектирование и разработка ведутся здесь) |
| `lab1/` (ветка `lab1`) | исходный код лабораторной работы №1 |
| `.gitignore` | исключение временных файлов IDE и сборки |

## Ветки

- `main` — стабильная версия;
- `lab1` — исходный код лабораторной работы №1;
- `ProjectTemplate` — заготовка проекта (слита в `main`);
- `lab3` — документирование бизнес-требований (SRS и макеты), вливается в `main` через pull request;
- `lab4` — системные требования: SDD, ADR, план итераций и переписка с Заказчиком, SRS 0.3 (продолжает `lab3`).

## Сборка проекта

```bash
cd project
javac -d out $(find src/main/java -name "*.java")
java -cp out by.bsuir.sdlc.Main
```
